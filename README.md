# 🧠 ChatGPT Sidebar Extension

*********************
❤️ Youtube link below :
https://www.youtube.com/watch?v=C-42_ZGgTIw&ab_channel=Furkan%C3%87elebi

A simple and useful Chrome Extension that adds a floating sidebar to ChatGPT. It automatically lists the messages and send to ChatGPT as buttons. Click any button to scroll directly to that message.

![image](https://github.com/user-attachments/assets/56e8cb06-451f-43e2-b61e-f8f5bc736c08)

---

## ✨ Features

- ✅ Lists all user messages in a sidebar
- 🖱️ Click any message to jump to its position
- ❌ Close (×) button to hide the panel anytime
- 🎨 Minimalist dark UI
